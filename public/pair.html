Paso 1: Activar Opciones de Desarrollador
  1. Abre Ajustes en tu teléfono Xiaomi.
  2. Toca en Sobre el teléfono.
  3. Toca 7 veces seguidas sobre Versión de OS (o Versión MIUI).
  4. Verás el aviso: "¡Ya eres desarrollador!".
Paso 2: Activar Depuración por USB
  1. Entra a Ajustes adicionales ➔ Opciones de desarrollador.
  2. Activa estas casillas indispensables:
    • ☑️ Depuración por USB
    • ☑️ Depuración USB (Ajustes de seguridad)
Paso 3: Conectar el Cable y Autorizar
  1. Enchufa el cable USB entre el teléfono y tu PC.
  2. En la pantalla de tu móvil saldrá la ventana de confirmación.
  3. Marca ☑️ "Permitir siempre desde esta computadora" y pulsa Aceptar.

local_fire_department Diagnóstico de Red & Reglas de Firewall (Puertos 3000 / 37020)
Si tu celular no detecta el servidor por Wi-Fi o el Radar UDP no responde, el firewall local puede estar bloqueando las conexiones.
UFW (Ubuntu, Debian, Arch Linux) sudo ufw allow 3000/tcp && sudo ufw allow 37020/udp && sudo ufw reload
Firewalld (Fedora, RHEL) sudo firewall-cmd --add-port=3000/tcp --add-port=37020/udp --permanent && sudo firewall-cmd --reload
Windows Defender Firewall (PowerShell) New-NetFirewallRule -DisplayName "ZenTrack 500Hz" -Direction Inbound -LocalPort 3000 -Protocol TCP -Action Allow
